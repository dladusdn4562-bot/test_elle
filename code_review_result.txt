1. index.html (HTML 문제점 및 불필요한 코드)
--------------------------------------------------------------------
[오류/중복] 돋보기 SVG 내 path 중복 작성 (84번째 줄 부근)
  - <svg> 내에서 `d="M18 18L25.0711 25.0711"` stroke 패스가 mask 안쪽(82번째 줄)과 외부에 중복으로 2번 들어가 있습니다.

[불필요] 비어있는 title 속성 (114번째 줄)
  - `<a href="..." target="_blank" title="">` 에서 title="" 속성이 비어있습니다. 사용하지 않는다면 삭제하는 것이 깔끔합니다.

[오류/불필요] 비어있는 리스트 아이템 및 클래스명 오타 (248번째 줄)
  - `<li class="swiper-slide"><div class="slide-atcbx"></div></li>` 
  - 내용이 비어있으며 `slide-atcbx` (atcbox의 오타로 추정) 요소가 의미 없이 삽입되어 있습니다.


2. normal.css (CSS 오류 및 불필요한 코드)
--------------------------------------------------------------------
[오류] 잘못된 CSS 속성값 사용 (18번째 줄)
  - `padding: auto;`
  - CSS 명세상 padding 속성에는 'auto' 값을 사용할 수 없습니다 (유효하지 않은 구문). padding: 0; 이나 적절한 px 단위로 수정해야 합니다.

[불필요] 주석 처리된 잔여 코드 (14번째 줄)
  - `/* background-color: pink; */` 주석 코드는 불필요하므로 제거하는 것이 좋습니다.


3. style.css (CSS 오류 및 불필요한 코드)
--------------------------------------------------------------------
[오류] display: block 요소에 Flexbox 속성 사용 (28~33번째 줄)
  - `.header-wrap`에 `display: block;`을 지정하였으나, 하단에 `flex-direction: column;`과 `gap: 33px;` 속성이 쓰였습니다.
  - `display: block` 상태에서는 flex 관련 속성이 적용되지 않습니다. (`display: flex;`로 변경 필요)

[중복] font-size 속성 중복 선언 (200, 204번째 줄)
  - `.atbox-txt` 선택자 안에 `font-size: 16px;`와 `font-size: 26px;`가 동시에 선언되어 있어 16px 선언이 무시됩니다.

[불필요/오류] 적용되지 않는 자식 선택자 (207번째 줄)
  - `.t2>p { padding-bottom: 52px; }`
  - HTML 구조상 `.t2` (<li class="t2">)의 직계 자식으로 <p> 태그가 존재하지 않아 해당 스타일이 전혀 적용되지 않습니다.

[오류] HTML 클래스명과 CSS 선택자 오타 불일치 (250번째 줄)
  - HTML에는 `<div class="scr-tit-wrap">`로 되어 있으나, CSS에서는 `.scr-tlt-wrap` (tit 대신 tlt)으로 오타가 나 있어 스타일이 적용되지 않습니다.

[오류] CSS 수치 단위 누락 (275번째 줄)
  - `.swiper-slide { width: 371; ... }`
  - 371 뒤에 px 단위가 누락되어 유효하지 않은 CSS 구문입니다 (`width: 371px;`로 수정 필요).

[불필요] 디버깅용 임시 테두리 코드 (287번째 줄)
  - `footer { border: 1px solid red; }` 빨간 테두리 디버깅 코드가 남아있습니다.
